# 10-12 DP1

과제가 나온 날의 강의 내용을 먼저 떠올리고, 그날 문제를 다시 풉니다.

1. `make lecture D=1012`로 그날 강의 가이드를 엽니다. 윈도우에서는 `lecture 1012`입니다. 가이드에서 장마다 떠올린 것을 적습니다.
2. WS부터 풀고 HW로 넘어갑니다.
3. 다 푼 뒤 가이드의 `강의에서 다룬 쪽`과 비교합니다.

강의 가이드는 저장소 밖에 있어서 이 저장소에는 올라오지 않습니다.
