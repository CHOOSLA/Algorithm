# SSAFY 알고리즘 다시 풀기

Lab에 제출했던 문제를 빈 `Solution.java`에서 다시 푸는 목록입니다. 폴더는 과제 날짜와 그날 강의 이름으로 묶었습니다. 늦게 제출한 과제도 과제가 나온 날에 들어가고, 같은 문제가 다른 과제에 다시 나오면 각각 남깁니다.

## 푸는 순서

1. `make review`로 오늘 풀 문제를 봅니다. 윈도우에서는 `review`입니다. 다시 풀 때가 된 문제가 먼저 나오고 그다음이 새 문제입니다. 화면에 쓰는 패키지는 처음 띄울 때 저장소의 `.venv`에만 설치됩니다.
2. 문제를 고르고 Enter를 누르면 문제 페이지와 이클립스의 `Solution.java`가 열리고 타이머가 돕니다. 혼자 붙잡고 있을 시간은 난이도로 정합니다. D3은 30분, D4는 40분, 모의 역량테스트는 50분이고 화면에서 `+`, `-`로 바꿉니다.
3. 막히면 화면에서 `h`를 누릅니다. 한 번에 한 단계씩 기법 이름, 개념 쪽, 강사 풀이 순서로 엽니다. 강의 자료가 있는 기기에서만 동작합니다.
4. 풀이를 봤으면 닫고 빈 파일에서 처음부터 다시 짭니다.
5. `make commit`을 실행하면 혼자 풀었는지와 막힌 지점을 묻고, 그 답을 기록합니다.

혼자 푼 문제는 복습을 마칩니다. 힌트를 봤으면 3일 뒤, 풀이를 봤으면 다음 날에 다시 나오고, 또 못 풀면 간격이 7일까지 늘어납니다. 다시 풀 때는 날짜와 강의 이름 없이 문제만 보여 줘서 어떤 기법을 쓸지부터 정하게 됩니다.

기록은 `log.json`에 시도마다 한 줄씩 쌓이고, 이 폴더의 README는 모두 거기서 만들어집니다. 손으로 고칠 파일은 없습니다. 강의 가이드와 강의 자료는 저장소 밖에 있어서 이 저장소에는 올라오지 않습니다.

## 푼 뒤 커밋하기

저장소 맨 위에서 `make commit`을 실행합니다. 윈도우에서는 `commit.cmd`를 더블클릭하거나 cmd에서 `commit`을 입력합니다. 바뀐 문제마다 결과를 묻고 `[복습 09-01] SEA(D3): 1225. 암호생성기` 형식의 커밋을 하나씩 만듭니다.

```sh
make commit
git push origin HEAD:main
```

## 목록 갱신

Lab 자료와 외부 git-dir을 최신으로 받은 뒤 실행합니다. 원격에 접속하거나 push하지 않으며, 기존 풀이와 복습 기록은 보존합니다. `--source`와 `--gitdirs`를 빼면 `manifest.json`만으로 목록과 README를 다시 만듭니다.

```sh
python3 scripts/prepare_ssafy_review.py --source ~/Dev/ssafy_study/99.Algorithm --gitdirs ~/Dev/algo-gitdirs
```

강의 가이드는 강의 자료가 있는 기기에서만 함께 갱신됩니다. 강의 자료가 바뀌면 `--pdfs`를 붙여 목차를 다시 읽습니다. 이때만 `pymupdf`가 필요합니다.

최초 생성 근거는 `manifest.json`에 있습니다.
