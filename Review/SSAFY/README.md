# SSAFY 알고리즘 다시 풀기

본인 이름의 Lab Java 풀이 커밋을 기준으로 만든 복습 목록입니다. 파일이 있다는 사실은 정답 판정을 뜻하지 않습니다.

날짜 폴더는 최초 본인 커밋의 author date를 한국 시간으로 바꾼 값입니다. GitLab 서버 수신 시각은 아니며, 과제 폴더 날짜는 별도로 표시합니다. 같은 문제가 다른 과제에 나오면 각각 남깁니다.

1. 날짜를 골라 문제 링크를 열고 빈 `Solution.java`에서 풉니다.
2. 문제별 README에 재풀이 날짜, 도움 사용 여부, 막힌 지점을 적습니다.
3. 풀이가 끝난 뒤 기존 코드와 비교하고 다음 복습 날짜를 정합니다.

## 목록 갱신

Lab 자료와 외부 git-dir을 최신으로 받은 뒤 실행합니다. 이 명령은 원격에 접속하거나 push하지 않습니다. 기존 풀이와 문제별 README, 날짜별 README의 메모는 보존하고 목록만 갱신합니다.

```sh
python3 scripts/prepare_ssafy_review.py --source ~/Dev/ssafy_study/99.Algorithm --gitdirs ~/Dev/algo-gitdirs
```

## GitHub에 기록 올리기

이 Algorithm 저장소에서 실행합니다. Lab 제출 명령과 별개입니다.

```sh
git add Review/SSAFY
git diff --cached --stat
git commit -m "study: SSAFY 알고리즘 재풀이 기록"
git push origin HEAD:main
```

최초 생성 근거는 `manifest.json`에 있습니다. 자동 목록 갱신으로 기존 재풀이 기록을 지우지 않습니다.
